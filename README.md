# POSSESSED

> "Your website is haunted by the barriers you built. Feel them. Then exorcise them."

A Kiroween 2026 hackathon project — Costume Contest category.

Possessed is an accessibility tool that lets developers *experience* the accessibility barriers on any web page, then fixes them live.

## Spirits

| Spirit | Simulates |
|---|---|
| 🌫️ The Fog | Low vision |
| 🩸 The Drain | Colour vision deficiency |
| 👁️ The Tunnel | Tunnel vision / glaucoma |
| 🔀 The Scramble | Dyslexia-like letter instability |
| 🤚 The Tremor | Motor tremor |
| 🕳️ The Void | Blindness / screen reader experience |

## Development

```bash
pnpm install
pnpm dev          # web app
pnpm dev:ext      # Chrome extension (watch)
pnpm test         # unit + property tests
pnpm test:e2e     # Playwright e2e
pnpm build        # production build
```
